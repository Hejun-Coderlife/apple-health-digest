# 健康数据压缩器

把 iPhone「健康」App 导出的几年数据，一页看懂：趋势图、作息图、训练统计、自动建议，还能一键整理成文字交给 AI 解读。

**在线使用：** https://hejun-coderlife.github.io/apple-health-digest/

## 怎么用

1. 手机打开「健康」App → 右上角头像 → 导出所有健康数据
2. 把「导出.zip」传到电脑（隔空投送或微信文件传输助手）
3. 打开上面的网页，把 zip 拖进去

## 隐私

所有计算都在你自己的浏览器里完成，文件不会上传到任何地方（不放心可以断网再用）。
结果只保存在这台电脑的浏览器里，点「清除记录」即可删除。

也可以下载 `index.html` 双击打开，离线使用。
